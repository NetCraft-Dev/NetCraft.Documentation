# Шаблон мода NetCraft

Пример кода для разработки модов NetCraft. Каждая запись в `NetCraftTemplate.yaml` указывает на один файл в `examples/`, а `ncm template` извлекает их по запросу.

## Использование

```
ncm template view              вывести список всех записей
ncm template view Wrapper.?    фильтровать по id, ? и * — подстановочные знаки
ncm template example <api id>  извлечь один пример файла в текущий каталог
```

## Два пути

`NetCraft.ModApi` предоставляет два пространства имён; выберите подходящее:

| Пространство имён | Что вы получаете |
| --- | --- |
| `NetCraft.ModApi.Wrapper` | События, фасады `Nc*` и дескрипторы `Nc*`. В публичной поверхности не появляется ни один тип ядра, поэтому переименование ядра не заставляет пересобирать ваш мод. |
| `NetCraft.ModApi.Extension` | Атрибуты `[Inject]` и `[Mixin]`. Правила напрямую называют типы и методы ядра, что мощнее и более хрупко. |

## Дескрипторы

`NcPlayer` и `NcLevel` — дескрипторы только для чтения. Всё, что они возвращают, — это обычная строка, число или логическое значение (`NcLevel.Dimension`, `NcPlayer.X`), но никогда не тип ядра, поэтому переименование ядра не заставляет пересобирать ваш мод. Операции с блоками принимают дескриптор уровня плюс `x y z`.

## Частые вызовы

Откройте эту панель внутри проекта мода, и каждый вызов ниже, который ваш код действительно использует, будет проверен по `NetCraftTemplate.yaml`: зелёный, если член объявлен; янтарный, если член отсутствует; красный, если тип вообще не объявлен. Наведите курсор на подсвеченное имя, чтобы увидеть причину.

| Вызов | Что делает |
| --- | --- |
| `NcServer.IsAvailable` | запущен ли сервер и захвачен ли он |
| `NcServer.Broadcast` | системное сообщение всем, кто в сети |
| `NcServer.Execute` | выполнить команду от имени консоли |
| `NcWorld.GetBlock` | прочитать один блок; null, если чанк не загружен |
| `NcWorld.SetBlock` | записать один блок; запускает всю цепочку обновления |
| `NcWorld.BreakBlock` | сломать блок так, как это сделал бы игрок |
| `NcWorld.Overworld` | дескриптор уровня Верхнего мира |
| `NcLevel.Dimension` | id измерения дескриптора уровня, например minecraft:overworld |
| `NcLevel.DayTime` | прочитать или задать время одного измерения |
| `NcPlayer.Name` | имя игрока |
| `NcPlayer.Health` | текущее здоровье |
| `NcPlayers.Find` | найти игрока в сети по имени |
| `NcPlayers.Send` | личное системное сообщение |
| `NcRegistries.FindState` | состояние блока по id с пространством имён |
| `NcRegistries.FindItem` | предмет по id с пространством имён |
| `ServerEvents.Tick` | выполняется каждый серверный tick |
| `ServerEvents.PlayerJoin` | игрок завершил подключение |
| `ServerEvents.BlockBroken` | блок был фактически заменён |
